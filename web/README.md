# 💼 個人全資產戰略管理中樞 (Web Asset Hub v2.0)

本系統是一套專為個人量化投資與資產配置設計的本地獨立 Web 管理中樞。
徹底解決手機截圖辨識浮動、漏看與手動修改成本丟失的問題，採用專業級會計與實時行情架構。

---

## 🌟 核心特色

1. **雙層會計架構 (Transactions -> Holdings)**：
   - 記錄每一筆買賣、存提與校正，持股與成本一律由時序日誌透過**移動加權平均成本法**自動回放計算，零手動計算出錯。
2. **多幣別與換匯成本拆分**：
   - 購買美股時完整記錄成交當下匯率與實際台幣扣款總額，將「美股資本利得」與「匯率損益」乾淨拆分。
3. **本地行情快取與休市 Fallback**：
   - 連線 TWSE 官方 JSON 端點與 Yahoo Finance，收盤行情以複合唯一鍵 `(date, ticker)` 寫入本地 SQLite，杜絕重複寫入膨脹。
   - 遇週末或休市日，自動讀取最新有效交易日價格，資產總值永遠正常計算。
4. **10 秒現金快速校準**：
   - 看一眼網銀，輸入目前餘額，系統自動計算差額並寫入一筆 `CASH_ADJUST` 日誌，10 秒內校對完畢。
5. **單一端口秒開 (Port 8000)**：
   - 前端 Vite React 編譯靜態資源由後端 FastAPI 統一託管，雙擊一個 `.bat` 即可秒開，無雙開視窗與跨域煩惱。

---

## 🚀 快速啟動

雙擊專案根目錄的 **`啟動資產管理中樞.bat`** 即可！
系統會自動啟動後端並在瀏覽器中打開 `http://localhost:8000`。
